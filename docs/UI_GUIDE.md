# UI 가이드

## 디자인 원칙
1. 매일 쓰는 분석 도구처럼 조용하고 작업 중심적으로 보이게 한다.
2. 첫 화면에서 채널 URL 입력, 분석 상태, 결과 확인 흐름이 바로 보여야 한다.
3. 마케팅 히어로보다 입력 폼과 결과 패널의 밀도와 가독성을 우선한다.
4. MVP 결과는 현재 화면 세션에만 남는다는 점을 UI 동작으로 자연스럽게 드러낸다.

## 화면 구성
- 상단: 제품명, 짧은 설명, MVP 범위 배지
- 입력 영역: YouTube 채널 URL 입력과 분석 버튼
- 상태 영역: 요청 중, 검증 오류, 분석 완료 상태
- 결과 영역: 실제 채널 제목, 채널 ID, 구독자/영상/조회수, 한국어 분석 요약, 핵심 관찰, 다음 액션

## 컴포넌트 기준
- Vue Single-File Component를 사용한다.
- Composition API와 `<script setup lang="ts">`를 기본으로 한다.
- 서버 응답 타입은 TypeScript interface로 명시하고 provider API key는 절대 포함하지 않는다.
- 화면 상태는 MVP 동안 `HomeView.vue` 내부 상태로 유지한다.

## 스타일 기준
- Vue SFC scoped CSS를 우선한다.
- 카드 안에 카드를 중첩하지 않는다.
- 버튼과 입력은 모바일에서도 줄바꿈과 높이가 깨지지 않게 고정된 리듬을 유지한다.
- 장식적 그라데이션이나 과한 AI 브랜딩은 피한다.
